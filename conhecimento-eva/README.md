# Base de conhecimento da EVA (RAG)

Pacote de documentos que a persona **EVA Vocal Coach** consulta no EVA Hub para
dar coaching. Todos em PT-BR, pesquisados em fontes de ciência da voz (Titze,
Sundberg, Miller, Roubeau/Henrich, Welch, Bozeman) e **checados factualmente**
(sem mitos tipo "cantar do diafragma"), coerentes com o produto (o DSP mede
números, a EVA interpreta; registro é estimativa; fadiga é bem-estar).

## Como usar

Faça **upload de todos os arquivos abaixo** na base de conhecimento da persona no
dashboard do EVA Hub (Assistants → EVA Vocal Coach → Conhecimento/RAG). Some a
eles a `fundamentacao-academica-vocal.md` (na raiz do projeto) e quaisquer papers
que quiser.

## Documentos

| Arquivo | Conteúdo |
|---|---|
| `respiracao-apoio.md` | Respiração costodiafragmática, appoggio (o que apoio É e NÃO é), pressão subglótica × afinação, exercícios |
| `registros-passaggio.md` | Mecanismos laríngeos M0–M3, peito/mix/cabeça/falsete, passaggio, desenvolver o mix (registro = estimativa) |
| `ressonancia-formantes.md` | Teoria fonte-filtro, formantes F1/F2, formante do cantor, twang, "colocação"/máscara, formant tuning nos agudos |
| `ciencia-da-voz.md` | Anatomia funcional: como pitch é produzido, fonte-filtro, o que jitter/shimmer/HNR/CPP significam |
| `saude-vocal.md` | Higiene vocal, aquecimento, fadiga (bem-estar), sinais de alerta p/ fono/otorrino, "canto não dói" |
| `biblioteca-exercicios.md` | Catálogo de exercícios: o quê, como, porquê, o que corrige (SOVT, sirenes, escalas, arpejos, messa di voce, mix…) |
| `problemas-solucoes.md` | FAQ troubleshooting: sintoma (+ métricas DSP) → causa → o que dizer + exercício |
| `pedagogia-aprendizado.md` | Aprendizado motor, VFB/KR, transferência, amusia × poor-pitch, autoeficácia |
| `estilo-repertorio-br.md` | Demandas vocais por gênero BR: sertanejo, gospel/louvor, MPB, pop/rock, pagode |
| `glossario.md` | ~35 termos vocais definidos (passaggio, appoggio, twang, formante, cents, jitter, SOVT…) |
| `tecnica-vocal.md` | Visão geral (documento starter) |

## Manutenção

Para atualizar/expandir, os documentos podem ser regerados/editados e re-subidos.
Mantenha a honestidade científica (nada de mitos; registro = estimativa; fadiga =
bem-estar, não diagnóstico).
